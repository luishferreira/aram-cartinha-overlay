# v0.1.0-alpha.1 — primeira versão experimental

Overlay para validar ARAM Mayhem no Windows, com identificação do campeão, leitura visual das ofertas/cartas escolhidas, indicadores por fonte, combos e importação dos arsenais do campeão selecionado. Sem Overwolf ou IA.

## Conteúdo

- Indicadores de Blitz, OP.GG, ARAMKit, ARAMGG e Mayhem.com, com métricas e escopos separados.
- Referências de builds de ARAMKit, OP.GG, Mayhem.com e LemonNation em 485 caminhos para 173 campeões. Blitz fica fora dos itens.
- Importação antes da partida, na seleção da fila Mayhem, com backups e preservação de outros conjuntos.
- Base de uso compacta, separada da pesquisa: SQLite de 130,6 MB; pacote de dados completo de 20,6 MB compactados.

Esta release contém **fontes e dados**. Ainda não inclui executável independente, instalador, launcher ou atualização automática. O código continua precisando de Python com Tkinter e das dependências declaradas.

## Instalação manual para testes

1. Clone o repositório e selecione a tag `v0.1.0-alpha.1`.
2. No Windows com Python 3.12/Tkinter, instale as dependências a partir da raiz do projeto:

   ```powershell
   python -m pip install -r requirements-debug.txt --target data/local/overlay-deps
   ```

3. Baixe os assets `data-b2ec781425b945a7674e69d9.zip`, `runtime-current.json` e `SHA256SUMS.txt` da release. Confira os hashes dos arquivos antes de instalar.
4. Crie a pasta `data/runtime/runs/b2ec781425b945a7674e69d9/` dentro do projeto e extraia nela o conteúdo do ZIP. Essa pasta deve conter diretamente `manifest.json`, `cards.sqlite3` e os quatro JSONs de dados.
5. Copie `runtime-current.json` para `data/runtime/current.json`.
6. Abra `Iniciar Debug.cmd` antes da seleção de campeão. `Ctrl+F8` oculta/mostra e `Ctrl+F9` encerra. `Preview Debug.cmd` abre a simulação sem importar arsenais.

O reconhecimento atual foi calibrado em **1920×1080, borderless, PT-BR**. Há catálogo de nomes em inglês; outras combinações de idioma, escala e layout ainda precisam de validação em outra máquina. O OCR local depende dos recursos de idioma instalados no Windows.

## Verificação realizada

- 72 testes focais passaram na máquina de desenvolvimento.
- 12.334 respostas iguais entre a base de pesquisa e a compacta, cobrindo os 173 campeões e contextos dos conjuntos copiados.
- Pacote de dados testado numa pasta sem pesquisa/SQLite original; duas gerações produziram o mesmo ZIP.
- Importação real dos arsenais e conferência por leitura no cliente, com idempotência e backups.

Não é uma validação completa em outros PCs. O reconhecimento visual pode ficar incerto ou incompleto e usa o nome do tooltip no TAB como última confirmação. Fontes têm versões distintas e classificações heurísticas; os dados não são uma previsão de vitória.

Logs, capturas, históricos, credenciais, backups pessoais e a base completa de pesquisa ficam fora do código e dos assets desta release. A instalação manual e os testes que exigem dados locais estão descritos em [arquivos do repositório](../repository-files.md) e [base de distribuição](../runtime-data-pack.md).
