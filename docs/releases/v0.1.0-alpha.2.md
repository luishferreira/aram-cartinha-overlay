# v0.1.0-alpha.2 — executável e instalador Windows

Esta versão inclui Python, dependências e o pacote de dados. Não é necessário instalar Python ou preparar os dados manualmente.

## Downloads

- **Setup-x64.exe:** opção recomendada para instalar e criar os atalhos.
- **Portable-x64.zip:** extrair a pasta inteira e abrir `AramCartinhaOverlay.exe`. Manter `_internal` e `data` junto dele.
- **SHA256SUMS.txt:** hashes dos downloads.

Abra o aplicativo antes da seleção de campeão. `Ctrl+F8` oculta/mostra e `Ctrl+F9` encerra. O menu Iniciar também tem os atalhos de prévia e encerramento. O instalador permite criar um atalho na área de trabalho.

## O que muda

- Executável Windows x64 e instalador por usuário, sem elevação administrativa.
- Históricos, logs e backups separados da instalação, em `%LOCALAPPDATA%\AramCartinhaOverlay`, preservados ao reinstalar/desinstalar.
- Diagnóstico opcional com `AramCartinhaOverlay.exe --self-test`, incluindo OCR sintético e consulta dos dados locais.
- Mesmo pacote de dados da alpha.1: cinco fontes de cartas, referências de combos e 485 caminhos de arsenais em 173 campeões.

Requer Windows 10 2004 ou superior, x64, com OCR/idiomas do Windows disponíveis. Calibrado para 1920×1080, borderless e PT-BR. O aplicativo e o instalador ainda não têm assinatura de editor. A atualização automática por launcher continua para uma etapa posterior.

## Verificação

89 testes passaram. O executável foi testado sem Python no PATH, a prévia renderizou os dados e a instalação/reinstalação/desinstalação preservaram o perfil de teste. Ainda é necessário validar a instalação em outro computador e o reconhecimento durante uma partida.
